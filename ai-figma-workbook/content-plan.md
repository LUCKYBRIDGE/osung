# 오성학교 활동지 콘텐츠 계획

## 1쪽. 피그마 교육용 계정 회원가입
1. Figma 회원가입/로그인 후 Education 페이지로 이동한다.
2. 교육용 인증에서 교사(Teacher) 유형을 선택하고 학교용 `gw1.kr` 계정을 사용한다.
3. 학교 및 역할 정보를 입력하고 인증 신청을 진행한다.
4. 인증 완료 화면에서 Education 권한이 적용되었는지 확인한다.

## 2쪽. ChatGPT / Claude에서 Figma 연결
### ChatGPT
1. 왼쪽 메뉴에서 플러그인/연결 메뉴로 들어간다.
2. Figma를 찾아 연결을 선택한다.
3. Figma 권한 승인 화면에서 연결을 허용한다.

### Claude
1. 설정의 커넥터/통합 메뉴로 이동한다.
2. Figma MCP 또는 Figma 연결 항목을 추가한다.
3. Figma 권한 승인 후 활성화 상태를 확인한다.

하단 확인: Figma 파일을 열고 AI에게 화면 읽기·디자인 생성 요청을 할 수 있으면 연결 완료이다.

## 3쪽. 프로젝트 폴더 만들고 활용하기
### ChatGPT
1. 프로젝트에서 새 프로젝트를 만든다.
2. 이름을 정하고 관련 파일·지침을 추가한다.
3. 프로젝트 안에서 새 대화를 시작한다.

### Claude
1. Projects에서 새 프로젝트를 만든다.
2. Project Knowledge/관련 파일 영역에 design.md와 참고 자료를 넣는다.
3. 프로젝트 안에서 대화를 시작하고 Figma 작업 요청을 이어간다.
