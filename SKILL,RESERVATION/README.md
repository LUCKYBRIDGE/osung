# 오성학교 스킬·예약 작업 활동지

2026.10.06 기준 개인 무료 계정을 중심으로 Gemini, ChatGPT, Claude의 **스킬**과 **예약 작업**을 비교하고 직접 따라 하는 A4 5장 활동지 작업 폴더이다.

## 구성
- `DESIGN.md`: 디자인 시스템, 무료 기능 범위, 페이지별 구조, QA 기준
- `content-plan.md`: 5페이지 콘텐츠 흐름과 캡처 매핑
- 기존 PNG 20장: 실제 서비스 단계별 화면 캡처

## 활동지 구성
1. 무료 기준 기능 지도 + 스킬/플러그인/예약 작업 개념
2. Gemini 스킬 만들기
3. Claude 스킬 만들고 사용하기
4. Gemini 예약 작업 만들기
5. ChatGPT 예약 작업 만들기

ChatGPT 무료의 Skills 생성 기능과 Claude 무료의 예약 작업은 지원 범위가 아니므로 상세 절차에서 제외한다. Gemini 기능은 개인 계정에 순차 배포될 수 있다.

## 제작 원칙
기존 `ai-figma-workbook`의 A4 단계형 활동지 스타일을 참고하되, 내용은 새로 구성한다. 실제 캡처를 우선하며, 지침과 첨부 자료를 더 구체화하고 각 서비스가 지원하는 외부 도구에 연결할수록 예시보다 발전된 반복 업무 흐름을 만들 수 있다는 점을 명시한다.

Figma 작업은 기존 오성학교 활동지 파일의 오른쪽에 새 A4 프레임 5개를 추가하는 방식으로 진행한다.
