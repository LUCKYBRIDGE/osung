# 오성학교 AI·Figma 실습 활동지

오성학교 교사를 대상으로 다음 세 가지를 A4 3장으로 안내하는 실습 자료이다.

1. Figma 교육용 계정 회원가입
2. ChatGPT / Claude에서 Figma 플러그인·MCP 연결
3. ChatGPT / Claude 프로젝트 폴더 만들고 활용하기

디자인 규격은 `design.md`를 단일 기준으로 사용한다. 실제 UI 화면은 캡처를 우선 사용하고, 재현이 필요할 때는 실제 화면과 거의 동일하게 만든다. 교육용 오버레이만 별도 추가한다.
