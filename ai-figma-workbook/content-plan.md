# 오성학교 활동지 콘텐츠 계획

## 1쪽. 피그마 교육용 계정 회원가입
1. Figma 회원가입/로그인 후 Education 페이지로 이동한다.
2. 교육용 인증에서 교사(Teacher) 유형을 선택하고 학교용 `gw1.kr` 계정을 사용한다.
3. 학교 유형과 교육 목적을 선택한다.
4. Figma for Education 인증 정보를 입력하고 신청한다.
5. 교육용 팀 업그레이드/완료 화면을 확인한다.

※ 인증 과정은 연속된 화면 2개를 하나의 단계로 묶어 보여줄 수 있다. 정보가 잘 보이는 기존 캡처는 자르지 않고 그대로 사용한다.

## 2쪽. ChatGPT / Claude에서 Figma 연결
### ChatGPT
1. 왼쪽 메뉴에서 플러그인/연결 메뉴로 들어간다.
2. Figma를 찾아 연결을 선택한다.
3. Figma MCP 권한 승인 화면에서 계정 연결을 허용한다.

### Claude
1. 사용자 지정/통합 메뉴에서 Figma를 찾는다.
2. Figma 연결을 추가하고 필요한 설정을 확인한다.
3. Figma MCP 계정 인증과 권한 승인을 마친다.

※ Claude처럼 인증 화면이 여러 장인 경우 1·2, 4·5 화면을 묶어 한 단계로 보여준다.

하단 확인: 실제 Figma 파일을 열고 AI에게 “이 Figma 화면을 읽어줘”, “이 디자인을 수정해줘”, “design.md를 기준으로 새 화면을 만들어줘”라고 요청해 본다. Figma 파일을 읽거나 디자인 작업이 시작되면 연결 완료이다.

## 3쪽. 프로젝트 폴더 + design.md + Figma 함께 활용하기
프로젝트 폴더는 단순히 파일을 저장하는 곳이 아니라, 반복 작업에 필요한 공통 맥락과 Figma 디자인 작업을 한 흐름으로 묶는 공간으로 안내한다.

### ChatGPT
1. 프로젝트에서 새 프로젝트를 만든다.
2. 이름을 정하고 `design.md`, 참고 이미지, 이전 결과물, 작업 지침을 추가한다.
3. Figma 플러그인이 연결된 상태에서 프로젝트 안에 새 대화를 시작한다.
4. “이 프로젝트의 design.md와 참고 이미지를 기준으로 Figma 파일을 읽고 활동지 화면을 만들어줘”처럼 요청한다.

### Claude
1. Projects에서 새 프로젝트를 만든다.
2. Project Knowledge/콘텐츠 영역에 `design.md`, 참고 이미지, 이전 결과물, 작업 지침을 넣는다.
3. Figma MCP가 연결된 상태에서 프로젝트 안에서 대화를 시작한다.
4. “프로젝트 자료를 기준으로 Figma의 현재 디자인을 확인하고 수정해줘”처럼 요청한다.

### 프로젝트에 넣으면 좋은 자료
- `design.md`: 글꼴, 크기, 여백, 색, 이미지 사용 규칙
- 참고 캡처 이미지: 실제 UI와 원하는 결과의 기준
- 이전 결과물(PDF·문서·이미지): 이어서 수정할 자료
- 작업 목적·금지사항을 적은 README/지침 파일

### 권장 작업 흐름
1. 프로젝트에 공통 자료를 넣는다.
2. Figma 플러그인/MCP를 연결한다.
3. 프로젝트 대화에서 Figma 읽기·수정·생성을 요청한다.
4. 결과를 Figma에서 확인한다.
5. 반복해서 적용할 규칙이 생기면 `design.md`도 함께 수정한다.
6. 수정된 `design.md`를 다음 Figma 작업에 다시 적용한다.

### 예시 요청 문구
`이 프로젝트의 design.md와 참고 이미지를 먼저 확인하고, 현재 Figma 활동지의 2쪽을 읽어줘. 실제 화면 캡처를 우선 사용하고 필요한 경우 두 이미지를 좌우나 상하로 묶어서 배치해줘. 수정이 반복해서 적용될 규칙이면 design.md에도 반영해줘.`
