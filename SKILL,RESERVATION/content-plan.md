# 오성학교 스킬·예약 작업 활동지 콘텐츠 계획

## 공통 원칙
- 2026.10.06 기준 개인 무료 계정을 중심으로 설명한다.
- 제품마다 무료 지원 범위가 달라 **실제로 무료에서 따라 할 수 있는 기능만 상세 단계로 구성**한다.
- 메뉴가 보이지 않는 경우 순차 배포·계정·지역 차이 가능성을 먼저 안내한다.
- 예시는 최소 구성이다. 실제 사용에서는 지침, 첨부 자료, 양식, 좋은 예시, 지원되는 외부 연결을 더할수록 결과가 정교해질 수 있음을 알린다.

## 1쪽 — 스킬·플러그인·예약 작업, 무엇이 다를까?
### 개념
- 스킬 = HOW: 반복할 방법과 기준
- 플러그인/앱/커넥터/MCP = WITH WHAT: 외부 서비스와 연결
- 예약 작업 = WHEN: 실행 시점을 정함

### 무료 기능 비교
- Gemini: 스킬 가능(순차 배포), Connected Apps 방식, 예약 작업 가능(순차 배포)
- ChatGPT: 무료 Skills 생성 미지원, 예약 작업 제한 지원
- Claude: 무료 Skills 지원, 예약 작업 미지원

### 하단 메시지
활동지의 예시는 시작점이다. 스킬 지침을 구체화하고 참고 파일·양식·이전의 좋은 결과물을 함께 제공하면 재사용성이 높아진다. 각 서비스가 지원하는 범위에서 캘린더·메일·Drive·Figma 등과 연결하거나 예약 작업과 스킬을 결합하면 더 실제적인 반복 업무 흐름으로 확장할 수 있다.

## 4쪽 — Gemini 예약 작업
1~6번은 다음 실제 흐름으로 구성한다.
1. 「예약된 작업」에서 「+ 새 작업」을 누른다. — 제미나이 예약작업 만들기1.png
2. 이름·요청 사항·실행 빈도·요일·완료 시간을 입력한다. — 제미나이 예약작업 만들기2.png
3. 이미 만든 스킬을 함께 쓰려면 요청 사항에 ‘관련 스킬을 적극 활용’ 같은 조건을 넣는다. — 제미나이 예약작업 만들기3.png
4. 정기적으로 만들 결과물의 대상·형식·표시 규칙을 구체적으로 적는다. — 제미나이 예약작업 만들기4.png
5. 예약 시간이 되면 결과가 채팅으로 자동 도착하는지 확인한다. — 제미나이 예약작업 만들기5.png
6. 결과를 본 뒤 대화로 기존 예약 작업 지침을 수정한다. — 제미나이 예약작업 만들기6.png

7번은 **실제 예약 작업 결과가 생성된 장면**으로 하단 전체 폭에 크게 배치한다.
- 제미나이 예약작업 만들기7.png
- 화면 속 요청 예시: “특수학교 학생들을 대상으로 한 안전 포스터를 만들어줘. 포스터에 적힌 달은 만든 달이 아니라 다음 달이 표시되게 해줘. 관련 스킬도 적극 활용해줘.”
- 교육 메시지: 예약 작업에서도 ‘다음 달 표시’처럼 결과 조건을 구체적으로 지정하고, 관련 스킬 활용까지 함께 요청하면 정기적인 결과물 제작 흐름으로 확장할 수 있다.

기본 예시 요청: “매주 월요일 아침, 이번 주 수업 준비 점검 항목을 5개로 정리해 알려줘.”

주의:
- Gemini Chat의 Scheduled actions를 설명한다.
- 별도의 Gemini Spark 예약은 유료 기능일 수 있으므로 혼동하지 않는다.
- 무료 계정의 예약 결과는 전달 전 여러 시간 앞서 준비될 수 있어 실시간 정보에는 맞지 않을 수 있다.

## 5쪽 — ChatGPT 예약 작업
실제 캡처의 의미에 맞춰 6단계를 구성한다.
1. 왼쪽 「예약」에서 반복할 업무와 주기를 자연어로 입력한다. — 챗지피티 예약 작업 만들기1.png
2. 날짜·시간·결과물 형식 등 필요한 조건을 더 구체적으로 적는다. — 챗지피티 예약 작업 만들기2.png
3. 무료 계정에서 정확한 시각 지정이 어렵다는 안내를 확인하고 가능한 유연한 일정으로 조정한다. — 챗지피티 예약 작업 만들기3.png
4. 실행된 결과를 확인하고 기간·선정 기준·출력 형식을 더 구체적으로 보완한다. — 챗지피티 예약 작업 만들기4.png
5. 예약 카드와 실제로 생성된 포스터 결과가 함께 나타나는지 확인한다. — 챗지피티 예약 작업 만들기5.png
6. 결과를 보고 ‘다음 달 표시’처럼 다음 실행부터 적용할 규칙을 추가한다. — 챗지피티 예약 작업 만들기6.png

무료 계정 핵심:
- 활성 작업 최대 3개
- 일회성 또는 하루 1회 이하 반복
- 유연한 시간창 중심
- 더 세밀한 시간·고빈도 실행은 유료 플랜 범위일 수 있음

마지막 확장 흐름:
**스킬/지침 → 참고 문서·양식 → 지원되는 외부 연결 → 예약/반복 실행 → 결과 확인·지침 개선**

Claude 무료 플랜에는 예약 작업이 없어 별도 단계 설명을 넣지 않는다.
