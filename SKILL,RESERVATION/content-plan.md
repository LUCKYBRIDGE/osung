# 오성학교 스킬·예약 작업 활동지 콘텐츠 계획

## 공통 원칙
- 2026.10.06 기준 개인 무료 계정을 중심으로 설명한다.
- 제품마다 무료 지원 범위가 달라 **실제로 무료에서 따라 할 수 있는 기능만 상세 단계로 구성**한다.
- 메뉴가 보이지 않는 경우 순차 배포·계정·지역 차이 가능성을 먼저 안내한다.
- 예시는 최소 구성이다. 실제 사용에서는 지침, 첨부 자료, 양식, 좋은 예시, 지원되는 외부 연결을 더할수록 결과가 정교해질 수 있음을 알린다.

## 1쪽 — 스킬·플러그인·예약 작업, 무엇이 다를까?
### 개념
- 스킬 = HOW: 반복할 방법과 기준
- 플러그인/앱/커넥터/MCP = WITH WHAT: 외부 서비스와 연결
- 예약 작업 = WHEN: 실행 시점을 정함

### 무료 기능 비교
- Gemini: 스킬 가능(순차 배포), Connected Apps 방식, 예약 작업 가능(순차 배포)
- ChatGPT: 무료 Skills 생성 미지원, 예약 작업 제한 지원
- Claude: 무료 Skills 지원, 예약 작업 미지원

### 하단 메시지
활동지의 예시는 시작점이다. 스킬 지침을 구체화하고 참고 파일·양식·이전의 좋은 결과물을 함께 제공하면 재사용성이 높아진다. 각 서비스가 지원하는 범위에서 캘린더·메일·Drive·Figma 등과 연결하거나 예약 작업과 스킬을 결합하면 더 실제적인 반복 업무 흐름으로 확장할 수 있다.
