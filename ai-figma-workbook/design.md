# 오성학교 AI 도구 시작하기 활동지 디자인 시스템

## 1. 목적
강릉오성학교 교사가 처음 보아도 별도의 설명 없이 따라 할 수 있는 A4 실습 활동지를 제작한다. 자료는 화면 캡처 중심의 단계형 안내이며, 실제 서비스 화면과 다른 장식적 재구성을 최소화한다.

## 2. 최종 산출물 구조
- 형식: A4 세로형 3장, PDF 출력 기준
- 1쪽: 피그마 교육용 계정 회원가입
- 2쪽: ChatGPT / Claude에서 Figma 플러그인(MCP·커넥터) 연결하기
- 3쪽: ChatGPT / Claude 프로젝트 폴더 만들고 활용하기
- Figma 원본: 모든 텍스트·도형·이미지 프레임이 편집 가능한 레이어로 유지한다.

## 3. 페이지 규격
- Figma 프레임: 794 × 1123 px (A4 비율 210:297)
- 바깥 여백: 38 px
- 안전 여백: 상·하 32 px, 좌·우 38 px 이상
- 기본 8 px 그리드 사용
- 페이지 내부 주요 모듈 간 간격: 18~24 px
- 카드 내부 패딩: 14~18 px
- 모서리 반경: 14 px
- 선 두께: 1~2 px
- 인쇄 시 화면 캡처가 너무 작아지지 않도록 캡처 최소 유효 폭 300 px을 권장한다.

## 4. 타이포그래피
- 기본 글꼴: Noto Sans KR
- 대제목: Bold, 29~32 px, 행간 1.2
- 페이지 설명/리드문: Regular 또는 Medium, 14~15 px, 행간 1.5
- 단계 제목: Bold, 17~18 px
- 본문: Regular, 13~14 px, 행간 1.5
- 보조 설명: Regular, 11.5~12.5 px
- 버튼명·메뉴명처럼 실제 UI 텍스트를 지칭할 때는 `「 」` 또는 굵게 표시한다.
- 한 문단은 2~3문장을 넘기지 않는다.

## 5. 색상
### 공통
- 배경: #F7F8FB
- 본문: #1E2430
- 보조 텍스트: #626B78
- 카드: #FFFFFF
- 카드 테두리: #DDE2EA
- 핵심 강조: #2563EB
- 완료/성공: #16875B
- 주의: #C87312
- 클릭 위치 강조: #E5484D

### 서비스 구분색
- Figma: #A259FF를 소량 사용
- ChatGPT: #10A37F를 라벨·아이콘 영역에만 사용
- Claude: #C15F3C를 라벨·아이콘 영역에만 사용
- 서비스 색은 페이지 전체 배경으로 사용하지 않는다.

## 6. 실제 화면 캡처 규칙
1. 실제 캡처가 충분히 선명하면 원본을 우선 사용한다.
2. 캡처가 흐리거나 불필요한 영역이 지나치게 많으면 핵심 UI만 크롭한다.
3. 재구성 화면을 사용할 경우 실제 화면과 거의 동일해야 한다.
   - 좌·우 패널 비율
   - 헤더와 메뉴 위치
   - 버튼·입력창 위치
   - 실제 메뉴명과 문구
   - 배경색, 테두리, 아이콘 배치
   위 요소를 임의로 바꾸지 않는다.
4. 원본 화면과 다른 가상의 버튼, 가상의 메뉴, 가상의 경로를 만들지 않는다.
5. 교육용 강조 요소만 별도 오버레이로 추가한다.
   - 빨간 클릭 테두리
   - 숫자 배지 ①②③
   - 짧은 화살표
   - 1~2줄 설명 말풍선
6. 화면을 본떠 그린 경우 캡처처럼 보이게 만들기 위해 내용을 단순화하지 않는다. 실제 UI를 최대한 그대로 재현한다.
7. 개인정보, 계정 이메일, 학교 내부 정보가 불필요하게 노출되면 해당 부분만 블러 또는 마스킹한다.

## 7. 단계 카드 구조
각 단계 카드는 다음 순서를 유지한다.
1. 번호 배지: 원형 또는 둥근 사각형, 26~30 px
2. 행동 제목: “왼쪽 아래 「플러그인」을 누른다”처럼 동사형
3. 화면 이미지: 카드 폭의 100%, 필요 시 핵심 크롭
4. 한 줄 설명: 1~2줄 이내
5. 확인 표시: 사용자가 직접 체크할 수 있는 □ 완료

## 8. 페이지별 레이아웃
### 1쪽 — Figma 교육용 계정
- 상단: 제목 + “gw1.kr 학교 계정으로 진행” 리드문
- 본문: 4개의 큰 단계 카드 또는 2×2 카드
- 마지막: “교육용 인증 완료 화면이 보이면 끝” 확인 박스
- 작은 이미지 7개를 억지로 넣기보다 핵심 4~5단계로 묶고, 한 이미지 안에서 세부 번호를 표시한다.

### 2쪽 — ChatGPT / Claude Figma 연결
- 상단: 제목 + “둘 중 사용하는 도구만 따라 하면 됨” 안내
- 본문: 좌측 ChatGPT, 우측 Claude의 2열 비교형
- 각 열 3단계 내외
- 하단: Figma에 연결된 뒤 나타나는 작업 환경 예시 1개를 가로 전체 폭으로 배치
- 서비스별 경로는 섞지 않는다.

### 3쪽 — 프로젝트 폴더 만들기
- 상단: 제목 + 프로젝트 폴더의 목적 1문장
- 본문 상단: ChatGPT 2~3단계
- 본문 하단: Claude 2~3단계
- 오른쪽 또는 하단에 “이 폴더에 넣을 파일” 체크리스트
  - design.md
  - 참고 이미지
  - 이전 결과물
  - 작업 지침
- 마지막에 “프로젝트 안에서 새 대화를 시작하면 자료를 다시 설명하는 수고를 줄일 수 있음”을 팁 박스로 배치한다.

## 9. 시각적 접근성
- 캡처 위 설명 글자를 직접 겹치지 않는다. 필요한 경우 외부 말풍선 사용
- 최소 본문 11.5 px 이상
- 빨강만으로 의미를 전달하지 않고 번호·화살표를 함께 사용
- 4.5:1 이상의 본문 대비를 목표로 한다.
- 중요한 캡처는 인쇄 상태에서도 UI 라벨이 구분되도록 과도하게 축소하지 않는다.

## 10. 금지 사항
- 실제 UI와 다른 ‘예쁜 가짜 화면’ 사용 금지
- 한 페이지에 7~10개의 매우 작은 캡처를 나열하는 방식 금지
- 스크린샷 위에 긴 문장을 겹치는 방식 금지
- 서로 다른 서비스의 색과 경로를 한 카드에 혼합 금지
- A4 바깥으로 개체가 나가거나 여백이 불균형한 구성 금지
- 같은 의미를 반복하는 설명 금지

## 11. QA 체크리스트
- [ ] 3개 페이지 크기가 모두 794×1123인가
- [ ] 동일한 제목·본문·카드 스타일을 사용하는가
- [ ] 실제 화면 또는 거의 동일한 재현 화면만 사용하는가
- [ ] 모든 클릭 위치가 번호/테두리로 구분되는가
- [ ] 캡처가 너무 작지 않은가
- [ ] 한 단계 설명이 2줄을 크게 넘지 않는가
- [ ] 개인정보가 불필요하게 노출되지 않는가
- [ ] PDF 출력 시 잘림이나 겹침이 없는가
- [ ] 초보자가 ‘다음에 무엇을 누르는지’ 바로 알 수 있는가
